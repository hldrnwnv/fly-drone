# Зрение и запах при пропусках визуальной метки

## Причина проверки

Новый [обонятельный декодер](../chase-odor-navigation/report.md) различает левый/правый запах и находит некоторые неподвижные источники, но не сопровождает движущуюся корову. В этом опыте визуальный `LC10a → DNa02` контроллер ведёт цель, пока метка доступна. Когда измерение метки закрыто, контроллер переключается на ветер или запах с ветром. У живых мух запах во время полёта взаимодействует со зрительными и ветровыми сигналами; простое следование мгновенной разнице концентраций не равно локализации источника ([van Breugel и Dickinson, 2014](https://www.sciencedirect.com/science/article/pii/S0960982213015820), [Kadakia и соавторы, 2022](https://www.nature.com/articles/s41586-022-05423-4)).

## Протокол

Три прежних старта `y=−0,45/0/+0,45` м, движущаяся корова, 18 с, одинаковый зрительный декодер и стабилизатор. В каждом 45 решений; на интервалах **4–6, 10–12 и 15–17 с** контроллеру не передаются угол и видимый размер розовой метки (15 решений). Сама метка остаётся на видео, но в эти моменты не может управлять дроном. Контроль `full_vision` проходит ту же сцену без пропусков. В доступные периоды все режимы используют один и тот же зрительный выход `DNa02`; при пропуске сравниваются: нулевой поворот, поворот только против ветра, ветер плюс идеальная разница концентраций, ветер плюс её оценка по спайкам ORN MaleCNS, а также обмен левой и правой антенн. Зрение и обоняние здесь моделируются **двумя отдельными экземплярами MaleCNS**; переключение и датчик ветра — внешняя инженерная логика, не доказанный механизм интеграции в мухе.

## Результат

| Режим | Успешных из 3 | Доля времени в зоне слежения по стартам |
| --- | ---: | --- |
| Метка всегда доступна | 2 | 0,774 / 0,809 / 0,660 |
| Пропуски; без помощи | 0 | 0,214 / 0,154 / 0,114 |
| Пропуски; только ветер | 1 | 0,663 / 0,709 / 0,629 |
| Пропуски; ветер + идеальный запах | 0 | 0,637 / 0,606 / 0,534 |
| Пропуски; ветер + ORN MaleCNS | 0 | 0,574 / 0,574 / 0,523 |
| Пропуски; стороны запаха обменены | 2 | 0,726 / 0,720 / 0,629 |

При пропусках направление ветра помогло относительно нулевого поворота, но добавление текущего запахового градиента ухудшило все три парных результата. Перестановка сторон оказалась лучше правильного входа. Это **не** означает, что анатомические стороны перепутаны: в траекториях с одним ветром знак `L−R` совпал с истинным углом на корову только в **16/38** пропущенных решениях, где оба сигнала были достаточно велики. Запаховый градиент в движущемся шлейфе здесь часто указывает на ось шлейфа, а не на текущее положение коровы. К тому же замкнутые полёты после первых разных команд видят разные участки шлейфа. Вывод ограничен тремя стартами и данной искусственной сценой.

**Что исправлено:** обонятельная сторона теперь читается из спайков ORN с отдельной калибровкой, ветер указан явно, зрительный выход не искажается запахом при видимой метке. **Что не исправлено:** предложенное правило `L−R → поворот` не даёт полезного сопровождения движущейся цели. Для следующего шага нужен иной алгоритм поиска по истории запаха и движения изображения, проверенный против ветрового и прямого сенсорного контролей на новых трассах. Простая смена знака, подсказанная тремя полётами, была бы подгонкой под эту сцену.

## Артефакты

Команда: `FLY_DATA="$PWD/data/flybrain" .venv/bin/fly-fpv chase-odor-fusion --output runs/chase-odor-fusion`. [Полные наблюдения, скрытые окна и траектории](results.json); [видео без запаховой помощи](masked_tag_only.mp4); [видео с нейронным обонянием](masked_tag_neural_odor.mp4). На видео «Tag masked» означает блокировку **данных для контроллера**, а не закрашивание метки для зрителя.
