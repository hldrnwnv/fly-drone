# Тип или группа нейронов

**Идентичность.** Название, сторона, конкретные body ID и версия MaleCNS. Если body ID ещё не проверены, так и написать.

**Опубликованные данные.** Отдельно: что измерено у живой мухи, точная ссылка и условия опыта.

**Коннектом.** Для каждого утверждения о связи: `pre body ID → post body ID`, число синапсов, порог/фильтр, релиз данных и ссылка на строку выгрузки или воспроизводимый запрос. Направление и тип связи не выводить из сходства названий.

**Наша модель.** Стимул, число выбранных клеток, считывание, контроль, зерна, окно измерения, численный эффект и ссылка на исходный результат.

**Граница вывода.** Что именно не установлено имеющимися данными.

**Следующая проверка.** Один конкретный вопрос, контроль и ожидаемый артефакт.

**Утверждения KAG.** Постоянные `id` соответствующих строк в [claims.jsonl](claims.jsonl).

**Связанные заметки.** Для каждой упомянутой клеточной группы используйте `[[Точное-имя-файла]]` или `[[Точное-имя-файла|подпись]]`. Связь поясняйте словами и `id`: ссылка сама по себе не означает прямой синапс.
