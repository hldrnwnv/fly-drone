# Timed photoreceptor input for FPV pursuit

Run: `FLY_DATA="$PWD/data/flybrain" .venv/bin/fly-fpv chase-retina --output runs/chase-retina` after installing `.[fpv,perception]`. The [receipt](results.json) records neural inputs, output commands, trajectory and latency for every decision. The [bearing](bearing_demo.mp4), [external flow](flow_demo.mp4), and [photoreceptor](retina_demo.mp4) videos show representative successful runs. The photoreceptor video overlays the **actual receptor luminance profile** derived from locally generated `retina_2_frames.npz`; the depth and RAFT panels are display only in this condition. This large frame array is excluded from Git and can be regenerated with the run command.

## Input path and controls

MaleCNS exposes 6006 photoreceptors with approximate horizontal azimuth, but no elevation coordinate in this packaged model. We convert the middle half of each 320×180 RGB frame to luminance, sample it at each photoreceptor's azimuth, and pass that vector through `FlyBrain.step(eye_drive=...)`. Ten real FPV frames per 0.4 s decision are replayed in order, two 20 ms neural ticks per frame. The first decision repeats its one available frame. We do not inject RAFT flow, learned depth, or artificial T4/T5 activity in the photoreceptor condition. The photo-to-retina optics, ON/OFF tuning, and cell coordinates are approximate.

`eye_drive` is **one 6006-element vector of input luminance**, not observed retinal spikes. The indexed cells include left- and right-eye photoreceptors, but both sides are sampled from the appropriate horizontal region of **one FPV camera**; this experiment has no separate eye cameras or stereo disparity. FlyBrain applies the values to receptor voltage and then simulates spikes through the graph. The line in the video bins this input vector by azimuth; it is not a recording of neural activity. In `chase-retina`, tag bearing still separately stimulates `LC10a`. The older `wing-direct --retina` diagnostic replaces that synthetic bearing input with receptor input.

All three flight conditions retain the camera tag bearing → `LC10a`, the same **bearing-trained and locked** `DNa02` readout, tag-size forward-speed rule, and conventional quad stabilizer. They use the same three initial seeds, cow motion, 40 ms FPV sampling, 20 neural ticks per decision, and RAFT/Depth Anything inference at each 0.4 s decision. The external-flow condition stimulates T4/T5 from RAFT as in the previous experiment. The retinal path adds its own projection cost; this is a matched sensory-input intervention, not a fully learned raw-video pilot. The locally generated `retina_2_maps.npz` and `retina_2_frames.npz` are linked by timestamps and camera hashes; both large arrays are excluded from Git.

| Input | Follow fraction in three 18 s flights | Tracked | Mean decision time |
|---|---|---:|---:|
| Tag bearing | 0.646, 0.809, 0.789 | 2/3 | 193 ms |
| Bearing + external RAFT flow | 0.586, 0.811, 0.806 | 2/3 | 195 ms |
| Bearing + timed receptor frames | 0.637, 0.740, 0.811 | 2/3 | 210 ms |

Tracking means at least 70% of the time after 4 s within the 1.4–3.5 m band behind the target and under 1 m lateral error. All nine flights completed. The decision timer excludes intermediate 40 ms camera rendering, so these timings do not establish real-time performance.

## What changed in the network

On the **same 135 saved bearing-flight observations**, the retinal input changed 116 turn-command values relative to bearing alone (mean absolute difference 0.068 on a −1 to +1 scale; five turn-sign changes on non-neutral frames). Replay of bearing alone reproduced every original command exactly, including frame hashes. Replaying the receptor frames in the correct order rather than repeating the last frame changed 114/135 commands (mean absolute difference 0.073); reversing the same frames changed 113/135 (0.062). T4/T5 spike totals were 417,635 for the correct sequence, 416,083 for a static frame, and 420,493 for the reverse sequence. These differences establish sensitivity to the input sequence; they do **not** establish useful direction sensing or improved pursuit. The `retina_only` receipt control omits LC10a stimulation but retains the tag-dependent output gain, so it is not a raw-video-only flight result.

A separate [moving-bar probe](motion_probe_12seeds.json) used the same MaleCNS retina input, a bright bar moving left-to-right or right-to-left, and a stationary bar, over 12 matched noise seeds. Mean spikes across all T4/T5 groups were 8076, 8167, and 8167 per 50-frame movie, respectively. Differences of individual cell groups were not consistent across seeds. Thus this implementation has **not yet demonstrated** the [direction selectivity measured in living-fly T4/T5 neurons](https://www.nature.com/articles/nature12320). The 1D projection blurs vertical scene structure; in the real pursuit frames its average receptor change between adjacent frames was only 0.0026 on a 0–1 scale. The next prerequisite is a source-grounded two-dimensional retinal map and response calibration on moving stimuli before attributing behavior to a biological visual computation.
