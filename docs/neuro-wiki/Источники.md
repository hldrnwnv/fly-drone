# Первичные источники для куратора wiki

Это стартовые источники для проверки утверждений. Ссылка в этом списке не подтверждает конкретную строку `claims.jsonl`: перед записью найдите в статье или данных точный фрагмент, версию, идентификатор и условия опыта.

| Источник | Для чего сверять | Граница |
| --- | --- | --- |
| [MaleCNS v1.0: загрузка и neuPrint](https://male-cns.janelia.org/download/) | Официальные аннотации, body ID, веса связей и релиз `male-cns:v1.0`. | Файлы `flybrain` содержат преобразованную знаковую матрицу; её веса не равны исходному числу синапсов. |
| [Полный коннектом мужской ЦНС](https://pmc.ncbi.nlm.nih.gov/articles/PMC12636603/) | Происхождение MaleCNS и описание набора данных. | Общие выводы статьи не подтверждают частный путь между выбранными клетками. |
| [Коннектом мужского брюшного нервного тяжа MANC](https://elifesciences.org/reviewed-preprints/97769) | Первичная реконструкция моторных и сенсорных цепей в VNC. | Это отдельный образец и набор данных; body ID не переносятся в MaleCNS напрямую. |
| [Цепи от нисходящих клеток к моторным в MANC](https://elifesciences.org/articles/96084) | Кандидатные пути `DNa04/05 → w-cHIN → b1/b3` и обсуждение возможных электрических контактов. | MANC и MaleCNS — разные наборы; перенос body ID или ребра требует явного сопоставления. |
| [FlyWire: полный коннектом мозга взрослой самки](https://www.nature.com/articles/s41586-024-07558-y) и [аннотации типов клеток](https://www.nature.com/articles/s41586-024-07686-5) | Сравнение устройства мозга и номенклатуры типов клеток. | Мозг самки не включает тот же образец MaleCNS; идентификаторы и частные рёбра нельзя переносить напрямую. |
| [Hemibrain: частичный коннектом центрального мозга](https://elifesciences.org/articles/57443) | Ранний набор для сравнения центральных цепей и типов клеток. | Объём реконструкции ограничен; обрезанные клетки и отсутствующие в объёме пути нельзя считать биологически отсутствующими. |
| [Проприоцепторы крыла](https://elifesciences.org/articles/107867) | Figure 1—figure supplement 1 сопоставляет `SNpp37/38` с сенсиллами тегулы, `SNpp06` — с дистальными малыми колоколовидными сенсиллами в номенклатуре MANC; исследованы аксоны FANC. | Соответствие меток и конкретных body ID в MaleCNS v1.0 ещё требует проверки; эффект нашей стимуляции — другое свидетельство. |
| [DNg02 и полётный мотор](https://pubmed.ncbi.nlm.nih.gov/35090590/) | Экспериментальная роль популяции DNg02 у живой мухи. | Не устанавливает механизм нашего ответа `flybrain` или управление квадрокоптером. |
| [DNa02 и руление при ходьбе](https://elifesciences.org/articles/102230) | Измеренная роль DNa02 и латеральной активности в ходьбе. | Контекст ходьбы не переносится автоматически на полёт. |
| [Мужская зрительная система](https://www.nature.com/articles/s41586-025-08746-0) | Аннотации и организация зрительных клеток в опубликованном наборе. | Не подменяет проверку зрительного входа нашей модели. |
| [Таблица зрительных колонок MaleCNS v1.0](https://github.com/flyconnectome/2025malecns/blob/67767d2233657983993ff6c2be48e836a935863c/supplemental_data/optic-column-type-assignments-v1.0.xlsx) | Исходные координаты колонок для `R7/R8` и `L1`, использованные в 2D пробе. | Положение части `R1–R6` было выведено нами через нормированный граф; таблица не задаёт углы зрения FPV-камеры. |
| [Избирательность T4/T5 к движению](https://www.nature.com/articles/nature12320) | Физиологический ориентир для проверки направленной чувствительности. | Отрицательный результат нашей одномерной проекции не опровергает результат на живых мухах. |

Локальные экспериментальные первоисточники находятся в `runs/<имя опыта>/results.json`; соответствующие `report.md` задают протокол и ограничения. Для полётного контура начните с `runs/directed-flight-circuits/`, `runs/wing-premotor-probe/` и `runs/chase-retina/`; для обоняния — с `runs/chase-odor-navigation/`.
