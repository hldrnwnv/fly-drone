# Saved experiment outputs

This directory contains the reports, JSON receipts, small fitted readouts, and demonstration videos used by the [research summary](../docs/research-results.md). Each report describes its scenario and controls; `results.json` contains the recorded decisions and trajectories where available.

Large `*_frames.npz` and `*_maps.npz` arrays are excluded from Git to keep the repository practical to clone. They can be regenerated with the command in the corresponding report. The saved JSON and videos remain available for inspecting the reported outcomes. Downloaded MaleCNS files are likewise excluded; see the setup instructions in the [README](../README.md).
